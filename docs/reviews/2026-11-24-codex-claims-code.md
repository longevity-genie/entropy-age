The repository supports a modest housekeeping and core-essential promoter gap in the named blood and cortex cohorts. It also supports substantial attenuation after expression matching in three settings. The evidence for cell division is narrower than the paper’s headline, and the Tet experiments measure a methylation state at one age. The shared code implements the basic matched contrast correctly on finite, aligned data, but the analyses differ in their matching, resampling, preprocessing and checks for estimability.

**Scope.** The named CSVs and `scripts/sesame_preprocess.R` were present in this checkout. I read the script and the relevant saved rows alongside the paper, Supplementary Tables S3–S4 and the run log. I used read-only file inspection and in-memory CSV calculations, including a Benjamini–Hochberg check. I made no changes and ran no analyses, tests, preprocessing or commands that write. I did not inspect raw IDATs, RRBS libraries, cluster-side audit files or sample-level rebuilt matrices. The per-test global FDR ledger, the saved Jena and mouse-atlas off-floor tables, the species-floor per-group Parquet, and the BJ and primary-astrocyte culture-bootstrap CSVs were unavailable. For those culture intervals I used the corrected run-log entry.

**HYPOTHESIS · Alternatives to add.** The Discussion considers composition, circularity and 5hmC. Two further alternatives matter for the headline. First, the gap can widen because look-alike CpGs become more age-responsive, even if absolute drift at the set CpGs stays unchanged. The Tet and senescence results show why both components matter. Second, the young samples estimate their own reference and remain in the slope fit. In-sample reference fitting can depress their observed divergence and create an age contrast that depends on CpG-specific dispersion and reliability. Matching on the reference mean does not control that effect. A split young reference would distinguish it. [`paper.md:265–275,318–322,670–691`, `stochasticity.py:152–162`]
